\section{Model Configurations for Network-Wide Forecasting}

To establish a rigorous benchmark for Sub-problem 2, we evaluate two foundational baseline architectures against our proposed TA-STGCN model \cite{stgcn, attention}. Both baseline models are intentionally configured with higher parameter capacity to prove that TA-STGCN's performance superiority originates from structural architectural innovation rather than parameter scaling.

\subsection{Evaluated Model Architectures}

\subsubsection{Baseline 1: GCN-LSTM}
Representing classical recurrent Spatio-Temporal Graph Neural Networks (STGNNs) widely adopted as standard baselines in urban traffic forecasting—such as T-GCN (Zhao et al., \emph{IEEE T-ITS} 2019) \cite{tgcn}, GC-LSTM (Lu et al., \emph{IEEE Access} 2020) \cite{gclstm}, and DCRNN (Li et al., \emph{ICLR} 2018) \cite{dcrnn}—GCN-LSTM combines a 2-layer static Graph Convolutional Network (GCN) \cite{gcn} for spatial topological feature extraction with a 2-layer Long Short-Term Memory (LSTM) network for sequential temporal modeling.
\begin{itemize}
    \item \textbf{Spatial Layer:} 2 static GCN layers \cite{gcn} with $C_{\text{gcn}} = 64$ hidden channels utilizing normalized symmetric graph Laplacian $A_{\text{norm}} = D^{-1/2} (A + I_N) D^{-1/2}$.
    \item \textbf{Temporal Layer:} 2-layer LSTM with $C_{\text{lstm}} = 160$ hidden units per recurrent cell.
    \item \textbf{Output Projection:} Shared Multi-Layer Perceptron ($160 \to 80 \to H$).
    \item \textbf{Parameter Footprint:} $\mathbf{364,198 \text{ trainable parameters}}$ (Highest parameter capacity).
\end{itemize}

\subsubsection{Baseline 2: Standard STGCN}
The classic STGCN architecture introduced by Yu et al. \cite{stgcn} (IJCAI 2018) utilizes convolutional blocks without attention mechanisms.
\begin{itemize}
    \item \textbf{Block Assembly:} 3 ST-Conv blocks ($NUM\_BLOCKS=3$).
    \item \textbf{Spatial Conv:} Chebyshev Spectral Graph Convolution ($K=3$) \cite{chebnet}.
    \item \textbf{Temporal Conv:} 1D Gated Linear Units (GLU) with temporal kernel size $K_t=3$ \cite{stgcn}.
    \item \textbf{Hidden Channels:} $C_{\text{hidden}} = 80$.
    \item \textbf{Parameter Footprint:} $\mathbf{303,846 \text{ trainable parameters}}$ (Second largest capacity).
\end{itemize}

\subsubsection{Proposed Model: TA-STGCN (Our Model)}
Couples 2 ST-Conv blocks \cite{stgcn} with a Model-Level Multi-Head Temporal Self-Attention module \cite{attention} post-ST-Conv blocks.
\begin{itemize}
    \item \textbf{Block Assembly:} 2 ST-Conv blocks ($NUM\_BLOCKS=2$, $C_{\text{hidden}}=64$, $K=3$) \cite{stgcn, chebnet}.
    \item \textbf{Attention Module:} Model-Level Multi-Head Temporal Self-Attention ($h=4$ heads, GELU Feed-Forward Network $64 \to 256 \to 64$) \cite{attention}.
    \item \textbf{Parameter Footprint:} $\mathbf{165,318 \text{ trainable parameters}}$ (Most lightweight architecture).
\end{itemize}

\subsection{Comparative Architectural Rationale and Parameter Allocation}

To enable a fair and transparent comparison across different learning paradigms, Table~\ref{tab:model_comparison} summarizes the structural components, feature dimensions, and parameter allocations for all evaluated models in Sub-problem 2.

The architectural choices in Table~\ref{tab:model_comparison} highlight three key computational trade-offs:
\begin{enumerate}
    \item \textbf{Spatial Convolution Operators:} Baseline 1 relies on 1st-order static GCN convolutions \cite{gcn, tgcn, gclstm}, which only aggregate immediate 1-hop spatial neighborhoods. In contrast, both Baseline 2 \cite{stgcn} and TA-STGCN utilize 3rd-order Chebyshev Spectral Polynomials ($K=3$) \cite{chebnet}, allowing the networks to capture multi-hop spatial dependencies across localized road neighborhoods without requiring dense matrix exponentiation.
    \item \textbf{Temporal Sequence Modeling Mechanisms:} Baseline 1 adopts sequential LSTM cells \cite{tgcn, gclstm}, which process historical time steps step-by-step ($t=1 \dots T_{\text{in}}$). While LSTMs effectively capture local temporal transitions, their sequential recurrence prevents parallel GPU acceleration and suffers from gradient attenuation over long horizons. Baseline 2 \cite{stgcn} resolves training latency by replacing RNNs with parallel 1D Gated Linear Units (GLU). However, local 1D convolutions possess fixed temporal receptive fields ($K_t=3$), restricting their ability to model non-stationary, long-range temporal correlations across the 24-step historical window. TA-STGCN bridges this gap by augmenting ST-Conv blocks with a Model-Level Multi-Head Temporal Self-Attention module ($h=4$) \cite{attention}, dynamically weighing temporal correlations across the entire 120-minute history.
    \item \textbf{Controlled Capacity Design:} To eliminate parameter scaling bias, Baseline 1 ($364,198$ parameters) and Baseline 2 ($303,846$ parameters) are intentionally allocated larger parameter budgets than TA-STGCN ($165,318$ parameters). Demonstrating superior forecasting accuracy with a 54.6\% parameter reduction over GCN-LSTM \cite{gcn, tgcn, gclstm} and 45.6\% reduction over STGCN Baseline \cite{stgcn} confirms that TA-STGCN's gains stem directly from structural temporal attention gating \cite{attention} rather than brute-force capacity expansion.
\end{enumerate}
